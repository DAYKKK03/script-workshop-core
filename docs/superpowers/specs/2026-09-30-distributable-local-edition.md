# 基础版可下载本地发行方案

## 已确认的用户目标

- 基础版继续在 GitHub 保存，保留商家项目、脚本生成、爆款选题、定制化脚本，不包含数字人。
- 用户不改业务代码即可在自己的电脑上使用，使用自己的外部服务 Key。
- 用户不需要安装 Docker。
- 本地数据库和后台任务由启动程序管理，不要求普通用户手动启动 PostgreSQL 或三个 Worker。

## 已确认交付形式

GitHub 保存源码；Releases 提供面向 Windows/macOS 的应用或便携发行包，包含所需运行环境。普通用户下载发行包，打开应用，在配置页填写自己的服务参数，保存后使用现有四个板块。

用户已确认按应用包交付。源码启动脚本不是普通用户的必经步骤。本文件不代表实现完成。

实现选择：Electron 提供窗口和内置 Node 运行环境；随包附带 PostgreSQL 16 二进制、FFmpeg、Next.js standalone 及三个编译后的 Worker。用户 Key 由操作系统安全存储加密后保存；设置页只通过限定的 IPC 访问配置。Windows x64、macOS arm64/x64 分别打包。发行包签名和公证状态必须如实披露，不伪称已签名。

## 应用运行职责

1. 首次启动创建独立数据目录和随机内部密钥，初始化全新数据库并运行迁移，不复用开发者数据库或密钥。
2. 保留账号、邀请码和项目归属校验；首次启动自动生成本地注册所需的邀请码，用户设置自己的账号密码。
3. 启动 Web 和三个后台 Worker；运行成功后显示现有网站界面。重复打开不重复启动数据库实例。
4. 关闭应用时停止自己启动的进程；重新打开后保留用户资料、配置和账号。升级覆盖应用包不覆盖数据目录。
5. Key 配置保存在本机，不提交到 GitHub，不打入应用包。缺少某项服务配置时明确提示该功能尚未配置。
6. 本地应用只监听回环地址；外部 AI、抖音提取和语音识别仍需联网，不承诺离线生成。

## 外部服务配置

按能力显示配置项：AI 内容生成；抖音视频提取；语音转写；需要时的媒体中转。并非所有能力只需要一个 Key，接口地址、资源 ID、模型和对象存储参数等应有合理默认值与清晰说明。提取功能不得绕过平台边界，失败文案继续遵守产品契约。

## 实施前已知问题

先处理独立验收发现的 Schema 索引一致性和生产依赖审计失败，并补齐小屏导航。现有 Docker 配置不作为终端用户安装前提。数据库打包必须保留 Prisma 和既有事务语义，不以换成另一种数据库来规避安装问题。

## 验收标准

- 在没有 Docker、Node.js、PostgreSQL 的干净目标环境中，从发行包完成首次启动。
- 用户通过页面配置自己的外部服务参数，不修改源码。
- 注册登录、商家 CRUD、权限和重启持久化通过真实数据库验证。
- 外部服务配置缺失与错误时明确失败；真实调用成功需单独使用合法测试输入验证。
- Windows 与 macOS 分别构建和验证，不以某个平台成功替代另一个平台。
- 数据和 Key 不进入发行包；升级不覆盖数据；关闭后无本应用遗留的数据库和 Worker 进程。
- GitHub 发布的每个包标注平台、架构、版本与验证情况。未验证的平台不能标成已支持。

## 当前状态

启动器、配置页、数据库迁移和后台任务编排已实现；本机源码构建的真实数据库测试通过注册、项目创建及重启后持久化。macOS/Windows 安装包和发行验证仍须以构建结果与 Release 状态为准。
