# 爆款选题内容策略库

## 设计理由

《8种爆款内容元素完整策略手册》作为方法论来源，已提炼为服务端固定、可测试的十元素策略库。运行时不读取外部 Markdown，避免把长文档、未知指令或不稳定文件路径带入 DeepSeek 请求。

手册中的“解释、共鸣、稀缺”作为生成方法映射：解释用于开篇和钩子的认知闭合，共鸣用于人群语言，稀缺只在商家资料有真实时间/库存/名额依据时使用成本或转化表达；“冲突”安全映射为“对立”。产品固定十元素分类仍保持不变。

## 设计优点

- Prompt 规则版本化、可审查，且不依赖部署环境中的外部文件。
- 标题、开篇、钩子都有具体场景、证据和兑现承诺要求，减少空泛模板。
- 每条选题使用 1 个主元素，必要时搭配 1 个辅元素，便于解释创作落点。
- 现有高风险元素安全规则继续生效；价格、库存、销量、资质、合作和效果不得虚构。
- 25 条选题要求不同切入角度，并继续由坐标、标题唯一性和安全校验兜底。

## 能力边界

本策略库只能指导 DeepSeek 生成更具体的标题、开篇、钩子和元素说明；它不读取实时热点、不验证商家事实、不承诺发布效果，也不生成完整口播脚本。

## 限制说明

- 策略库无法替代真实商家资料。资料越少，生成内容越保守，必要时会拒绝不充分资料。
- “稀缺”“成本”等表达只允许使用商家资料中的真实依据，系统不会自行补价格、库存或时间。
- 模型仍可能返回结构不合格内容；服务端最多进行一次语义重试，失败时不展示半成品且不扣成功额度。
- 普通标题模式会被拒绝，但标题是否真正有传播力仍需 staging 真实验收和人工判断。
