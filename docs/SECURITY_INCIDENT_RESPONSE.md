# 安全事件处理清单

1. 立即判断范围：账号异常、后台异常、API 费用异常、Provider 泄露、数据库或服务器入侵。
2. 提取链路异常先设置 `DOUYIN_PROVIDER=blocked`；费用异常同时停用对应供应商 Key。
3. 撤销受影响用户或管理员的数据库会话，停用账号；管理员密钥疑似泄露时轮换 TOTP 加密密钥需先重新绑定全部管理员。
4. 轮换 `SESSION_SECRET`、API Key、数据库密码、COS 密钥和部署 SSH Key。不要在聊天、工单或日志中粘贴旧值。
5. 在保留只读证据后隔离源站；检查审计日志、云防火墙、EdgeOne 和供应商账单。不得导出 transcript 或生成文案用于排障。
6. 从已验证的干净镜像重建服务；数据库恢复只使用通过校验的加密备份。
7. 记录时间线、影响账号、费用和修复措施；通知受影响用户时不披露攻击细节或其他用户数据。
8. 恢复后提高告警敏感度并完成复盘，补测试和自动化防线。
