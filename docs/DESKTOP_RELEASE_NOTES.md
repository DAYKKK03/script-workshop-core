# 脚本工坊基础版 v0.2.0

本版本保留商家项目、参考脚本生成、爆款选题、定制化脚本，不包含数字人。用户下载对应系统和架构的应用包后，无需另装 Docker、Node.js 或 PostgreSQL。首次打开在配置页填写自己的服务参数，点击「启动应用」，再用页面显示的邀请码注册本机账号。

应用内的数据和密钥只保存在当前电脑；服务密钥由操作系统安全存储加密。DeepSeek、TikHub、火山引擎等外部能力需要用户自己的合法服务配置及网络。未配置时不会模拟生成结果。Windows 请以普通权限启动应用，不要选择「以管理员身份运行」。

安装包目前未签名、未做 macOS 公证。系统出现未知开发者或 SmartScreen 提示时，请核对下载来源和 `SHA256SUMS.txt`。本版本的 GitHub 构建工作流分别使用 Windows x64、macOS arm64、macOS x64 环境打包，并在包内启动数据库和应用完成健康检查与注册烟测；真实外部服务调用未包含在自动测试内。
