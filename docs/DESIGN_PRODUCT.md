# Design Product Standard

## 目的

本文档用于沉淀「脚本工坊」网页主内容区的产品视觉标准，作为后续 UI 设计、前端实现和验收的共同依据。

当前标准基于：

1. 项目 PRD v1 的产品定位。
2. 已确定的基础风格：暗色玻璃工作台 + 蓝橙动态光栅。
3. React Bits `Gradient Blinds` 动效方向。
4. 用户提供的光感胶囊 CTA 参考图。
5. Lucide 图标库。

「爆款选题」页面遵循 [`TOPIC_IDEAS_DESIGN_SPEC.md`](./TOPIC_IDEAS_DESIGN_SPEC.md)，当前已实现真实登录入口与生成链路；是否开放生产仍以 staging 验收状态为准。

「定制化脚本」页面遵循 [`CUSTOM_SCRIPT_DESIGN_SPEC.md`](./CUSTOM_SCRIPT_DESIGN_SPEC.md)。真实登录入口已接入持久任务、独立 Worker、轮询恢复、取消、复制和换一版；开发环境固定样本预览仍不得被当作真实功能，staging 真实 DeepSeek 与事实边界验收完成前不得推生产。

## 产品视觉定位

网页主内容的视觉关键词：

- 专业运营工具
- 暗色玻璃
- 蓝橙光感
- 动态光栅
- 清晰工作流
- 内容可复制

不要做成：

- 纯营销落地页
- 过度装饰的 AI 炫技页
- 大面积紫色渐变页
- 影响表单和脚本文案阅读的强动效页面
- PRD 外功能展示页

## 设计参考融合原则

外部 React/UI 参考只作为视觉语言，不作为产品功能来源。所有页面必须先满足 PRD v1 的业务边界，再决定是否使用动效。

融合原则：

1. 首页、登录页、注册页负责建立品牌记忆，可以使用更强的背景光感和卡片动效。
2. 生成页、项目页、工作台负责高频操作和长文本阅读，只允许克制反馈，不允许强动效覆盖正文、表单和资料输入区。
3. 橙色是唯一主强调色。允许蓝色作为空间背景，禁止回到紫色默认主题。
4. 动效必须服务状态反馈：进入、hover、点击、处理中、复制成功或失败。
5. 所有动效必须尊重 `prefers-reduced-motion`，移动端自动降低复杂度。
6. 外部组件不得引入 PRD 外入口，例如支付、会员、历史记录、上传、手动粘贴、站内编辑、社交登录、忘记密码和记住我。

## 页面层级标准

### 公开首页

公开首页是用户进入登录前看到的页面，承担「建立产品印象 + 引导登录」的作用。

标准结构：

1. 首屏 Hero
2. 主 CTA
3. 三步流程
4. 适用对象
5. 第一版边界说明

当前确认：公开首页不需要顶部导航。首页应保持聚焦的封面式入口，避免增加额外导航项干扰主 CTA。

首页主 CTA 点击后进入 `/login`。注册入口放在登录页内，不在首页制造双主按钮。

### 登录和注册页

登录/注册页允许延续首页的强视觉氛围，但表单必须更清晰。

标准结构：

1. 品牌区
2. 登录/注册切换
3. 表单卡片
4. 错误提示
5. 表单提交按钮

登录/注册页可使用外部参考组件中的动效语言，但不得照搬颜色和业务入口。

允许提取：

- 表单卡片边框巡游光束。
- 角点微光呼吸。
- 卡片轻微 3D 浮动。
- 按钮 hover、active 和 loading 扫光。

不允许照搬：

- 紫色主背景。
- 白色主按钮。
- Google 登录。
- 忘记密码。
- 记住我。
- 与 PRD v1 无关的登录方式。

登录/注册动效统一套用项目蓝橙暗色玻璃风格，并尊重 `prefers-reduced-motion`。

### 工作台和业务页

工作台、项目页、生成页是工具页面，必须优先效率。

标准结构：

1. 左侧或顶部导航
2. 页面标题和说明
3. 主操作区
4. 表单区
5. 结果展示区
6. 状态反馈

业务页不要使用大面积强动效，避免干扰脚本文案阅读。

## 视觉标准

### 背景

首页首屏使用 `Gradient Blinds` 方向的动态背景：

- 颜色：深黑 `#02030a`、深蓝 `#061026`、品牌蓝 `#1658f9`、白色高光和橙色 `#ff7a1a`
- 角度：斜向约 `100deg - 115deg`
- 噪点：低到中等，避免脏感
- 形态：斜向百叶光束
- 动效：用户不移动鼠标时，2-3 秒内能感知缓慢变化
- 鼠标：允许轻微聚光跟随

业务页背景使用更克制的深色玻璃氛围：

- 允许低透明动态背景
- 不使用高噪点百叶光束覆盖正文
- 不让背景抢过表单、项目资料和生成文案

### 主 CTA

首页主 CTA 使用光感胶囊按钮。

标准：

- 文案：`开始使用`
- 链接：`/login`
- 高度：`64px - 76px`
- 最小宽度：`220px`
- 圆角：胶囊圆角，`999px`
- 背景：蓝白橙柔和光晕
- 文字：近黑色，半粗或粗体
- 图标：右侧使用 Lucide `send` 或 `send-horizontal`
- Hover：轻微提亮、轻微上浮
- Active：轻微压下

主 CTA 只用于首页首屏。业务页主按钮继续使用克制的橙色渐变按钮。

### 面板

统一使用暗色玻璃面板：

- 背景：`rgba(12, 12, 14, 0.58)`
- 可读面板：`rgba(5, 5, 6, 0.72)`
- 边框：`rgba(255, 255, 255, 0.12)`
- 模糊：`blur(16px - 20px)`
- 圆角：工具面板 `8px`，登录/首页卡片可用 `16px - 24px`
- 阴影：柔和黑色大阴影

不要把卡片套卡片。页面区块不做浮动大卡，重复项目、表单容器、结果容器才使用卡片。

### 板块动效

板块卡片可使用橙色版 `MagicBento` 动效作为 hover 和点击反馈。

标准：

- 主色：橙色光效，默认 RGB 为 `255, 122, 26`。
- 使用范围：工作流说明、能力板块、状态卡片、步骤卡片。
- 不用于：大段文案容器、表单输入框、最终脚本文案阅读区。
- Hover：轻微聚光、边框发光、可选微弱磁吸。
- Click：橙色 ripple 点击扩散。
- 粒子：数量控制在 `8 - 12`，避免喧宾夺主。
- Mobile：自动关闭复杂动效。
- 减少动态：尊重 `prefers-reduced-motion`。

AI 生成按钮在加载状态下可使用 `AnimatedShinyText`。光效必须使用橙金色，不使用紫色默认效果。

## 间距标准

使用 4px 基础栅格。

| 用途 | 标准 |
|---|---:|
| 页面外边距 mobile | `20px` |
| 页面外边距 desktop | `32px - 40px` |
| 主内容最大宽度 | `1120px - 1280px` |
| 顶部导航高度 | `64px - 76px` |
| Hero 标题与副标题 | `20px - 28px` |
| 副标题与主 CTA | `32px - 44px` |
| 卡片内边距 compact | `16px` |
| 卡片内边距 normal | `20px - 24px` |
| 表单字段间距 | `16px` |
| 分组间距 | `24px - 32px` |
| 页面主区块间距 | `48px - 72px` |

生成页主流程建议使用单列优先，避免复杂双栏让用户找不到下一步。

## 字号标准

字体使用系统字体：

`Inter, system-ui, -apple-system, BlinkMacSystemFont, "PingFang SC", Arial, sans-serif`

| 场景 | 字号 | 行高 | 字重 |
|---|---:|---:|---:|
| 首页 Hero 标题 | `64px - 88px` | `1.0 - 1.08` | `700` |
| 页面标题 | `28px - 32px` | `1.2` | `700` |
| 卡片标题 | `18px - 22px` | `1.3` | `700` |
| 分组标题 | `15px - 16px` | `1.4` | `600` |
| 正文说明 | `14px - 16px` | `1.65 - 1.8` | `400` |
| 表单标签 | `14px` | `1.4` | `600` |
| 输入文字 | `14px - 15px` | `1.5` | `400` |
| 辅助说明 | `12px - 13px` | `1.6` | `400` |
| 按钮文字 | `14px - 16px` | `1.2` | `600` |

业务页不要使用过大的标题。首页可以大标题，工作台和生成页保持信息密度。

## 图标标准

图标统一使用 Lucide。

Lucide 默认标准：

- `size: 24px`
- `strokeWidth: 2`
- 线性图标

本项目使用建议：

| 场景 | Lucide 图标 | 用途 |
|---|---|---|
| 首页主 CTA | `send` 或 `send-horizontal` | 开始使用、进入流程 |
| 登录 | `log-in` | 登录入口 |
| 注册/账号 | `user-round` 或 `circle-user-round` | 用户身份 |
| 工作台 | `layout-dashboard` | 工作台入口 |
| 商家项目 | `store` 或 `building-2` | 商家/门店项目 |
| 新建项目 | `circle-plus` | 创建项目 |
| 编辑项目 | `pencil` 或 `square-pen` | 编辑 |
| 删除项目 | `trash-2` | 删除 |
| 抖音链接 | `link` | 链接输入 |
| 自动提取 | `sparkles` 或 `bot` | AI/自动能力 |
| 结构拆解 | `list` 或 `clipboard-list` | 脚本结构 |
| 时长选择 | `clock` | 脚本时长 |
| 生成脚本 | `file-text` 或 `sparkles` | 文案生成 |
| 复制 | `copy` | 一键复制 |
| 成功 | `circle-check` 或 `circle-check-big` | 成功状态 |
| 错误 | `triangle-alert` 或 `circle-alert` | 错误状态 |
| 外部链接 | `external-link` | 外部跳转 |
| 设置 | `settings` 或 `sliders-horizontal` | 参数/偏好 |
| 返回 | `arrow-left` | 返回上一页 |
| 继续 | `arrow-right` 或 `move-right` | 下一步 |

图标尺寸规范：

- 顶部导航：`18px - 20px`
- 普通按钮：`16px - 18px`
- 首页主 CTA：`22px - 24px`
- 状态提示：`16px`
- 卡片装饰图标：`20px - 24px`

不要使用不明来源 SVG。能用 Lucide 的地方优先用 Lucide。

## 主内容标准

### 首页主内容

首页主内容要直接说明产品价值，不铺太多营销话术。

推荐文案结构：

```text
脚本工坊
把抖音参考视频拆成结构，再结合商家资料生成可直接复制的新口播脚本。

[开始使用 →]

粘贴抖音链接 → 自动拆解结构 → 生成商家新脚本

适合本地生活商家、门店老板、探店运营和短视频代运营。
第一版仅支持抖音链接自动提取；不支持导入视频或音频，也不提供直接粘贴口播文案兜底。
```

### 生成页主内容

生成页必须按流程组织：

1. 选择商家项目。
2. 输入抖音链接。
3. 提取原口播。
4. 展示参考结构。
5. 选择时长。
6. 生成完整脚本。
7. 复制结果。

每一步只展示当前需要用户理解和操作的信息，不提供站内编辑器，不保存历史记录。

### 状态反馈

错误提示：

- 抖音提取失败必须固定展示：`当前链接无法自动提取，请更换可提取的抖音视频链接`
- 不展示平台内部错误、密钥、接口和堆栈信息。

成功提示：

- 复制成功：`已复制`
- 保存成功：`已保存`

加载状态：

- 使用按钮 loading 文案或 `loader-circle` 图标。
- 不要用全屏遮罩阻断用户阅读已有结果，除非是首次页面加载。

## 验收清单

后续实现或验收时按以下标准检查：

1. 首页首屏是否能看到明显但不刺眼的 `Gradient Blinds` 动效。
2. 首页主 CTA 是否为蓝白橙光感胶囊按钮。
3. 点击首页主 CTA 是否进入 `/login`。
4. 登录页是否仍可切换注册。
5. 业务页是否克制，没有强动效干扰工作流。
6. 页面间距是否落在 4px 栅格和本文档标准范围内。
7. 字号是否符合页面层级，不出现业务页超大标题。
8. 图标是否来自 Lucide，且语义匹配。
9. 抖音提取失败提示是否使用固定文案。
10. 页面是否没有 PRD 明确不做的入口。
